# Oracon
Orienteering radio control using NB-Iot SIM7028 module and ESP32S3. Originally a bachelor thesis for FIT CTU.

## Technologies
- **Gate** - Spring boot, PostgreSQL
- **End devices** - PlatformIO, C++

## Hardware
- Custom made PCB with a LiPol battery and custom case.

## SI compatibility
- SI BSF 7 stations with RS232 or USB
- SI SRR dongle
- SI SRR module to be implemented
